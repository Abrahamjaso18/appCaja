  App Caja Registradora

Es una aplicación web diseñada para gestionar ventas y facturación en una empresa que vende Productos de Costruccion. Permite registrar clientes, agregar productos, calcular totales en múltiples monedas (USD, COP, Bs) y generar facturas detalladas. Incluye un panel de administración para gestionar productos y tasas de cambio.

  Características principales
Autenticación de usuarios: Sistema de login para empleados y administradores

* Gestión de clientes: Registro de datos del cliente (nombre e identificación)

* Catálogo de productos: Búsqueda y adición de productos desde base de datos

* Cálculo multi-moneda: Conversión automática a dólares, pesos colombianos y bolívares

* Generación de facturas: Creación de comprobantes de venta con detalles de productos y totales

* Panel de administración:
    - Añadir nuevos productos
    - Actualizar tasas de cambio
    - Gestión de usuarios
    - Generador de Reporte diario ventas productos bajos en stock
 
   Tecnologías utilizadas:
  
Frontend: HTML5, CSS3, JavaScript (ES6+)

Backend: Firebase (Authentication, Realtime Database)

Dependencias: Firebase SDK (v11.2.0)
